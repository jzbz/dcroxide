  addendum reads these together as the bar to merge: the soak passed on the
  ported code, and the port within those two bounds, after speed work where

  back to the project owner. A new ADR, numbered when it is written, then
  supersedes ADR-0006. None of this is done.

- **D7** — accepted 2026-10-26 as policy, as ADR-0014. The MSRV stays the
